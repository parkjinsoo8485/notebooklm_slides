# 📜 한국어 표준 발음법 및 TTS 정밀 음성 변환 규정 가이드

본 문서는 **국립국어원 표준 발음법**을 기반으로, AI 음성 합성(TTS) 시 인공지능 특유의 딱딱한 철자식 발음(Spelling-pronunciation)을 방지하고 **100% 실제 성우의 자연스러운 연음 및 구어 발음**을 구현하기 위한 공식 표준 변환 지침서입니다.

---

## 📌 1. 핵심 발음 규칙 및 TTS 변환 원칙

### 1) 조사 '의'의 [에] 발음 (표준 발음법 제5항)
* **규칙**: 단어의 첫음절 이외의 '의'는 [이]로, **관형격 조사 '의'는 [에]로 발음**하는 것이 가장 자연스럽고 표준 발음으로 허용됩니다.
* **적용 예시**:
  * `문밖의` ➔ **[문바께]** (TTS 입력: `문밖에`)
  * `마님의` ➔ **[마니메]** (TTS 입력: `마님에`)
  * `가문의` ➔ **[가무네]** (TTS 입력: `가문에`)
  * `우리의` ➔ **[우리에]** (TTS 입력: `우리에`)
  * `세상의` ➔ **[세상에]** (TTS 입력: `세상에`)

---

### 2) 연음 법칙 (표준 발음법 제13항, 제14항)
* **규칙**: 홑받침, 쌍받침, 겹받침 뒤에 모음으로 시작하는 조사·어미·접미사가 올 때 받침 자음이 뒷 음절 첫소리로 넘어가 발음됩니다.
* **적용 예시**:
  * `문밖의` ➔ **[문바께]** (ㄲ이 뒷음절 첫소리로 연음)
  * `흙바닥에` ➔ **[흑바다게]** (ㄺ 중 ㄱ이 연음)
  * `밤낮을` ➔ **[밤나즐]** (낮을 ➔ [나즐])
  * `꽃잎이` ➔ **[꼰니피]** (ㄴ첨가 + 연음)
  * `달빛조차` ➔ **[달비쪼차]** (빛조차 ➔ [비쪼차])
  * `옷깃을` ➔ **[오기슬]** (옷깃을 ➔ [오기슬])
  * `목숨을` ➔ **[목쑤믈]** (목숨을 ➔ [목쑤믈])

---

### 3) 비음화 및 유음화 (표준 발음법 제18항, 제20항)
* **규칙**: 받침 'ㄱ, ㄷ, ㅂ' 뒤에 'ㄴ, ㅁ'이 오면 [ㅇ, ㄴ, ㅁ]으로 발음 / 'ㄴ'과 'ㄹ'이 만나면 [ㄹ, ㄹ]로 발음
* **적용 예시**:
  * `백 년` ➔ **[뱅 년]**
  * `십 년` ➔ **[심 년]**
  * `국문` ➔ **[궁문]**
  * `군량미` ➔ **[군냥미]** 또는 **[굴량미]**
  * `신문로` ➔ **[신문노]**

---

### 4) 구개음화 (표준 발음법 제17항)
* **규칙**: 받침 'ㄷ, ㅌ'이 조사나 접미사의 모음 'ㅣ'를 만나면 [ㅈ, ㅊ]으로 발음
* **적용 예시**:
  * `굳이` ➔ **[구지]**
  * `같이` ➔ **[가치]**
  * `붙이다` ➔ **[부치다]**
  * `맏이` ➔ **[마지]**

---

### 5) 경음화(된소리되기) (표준 발음법 제23항 ~ 제28항)
* **규칙**: 받침 'ㄱ, ㄷ, ㅂ, ㅅ, ㅈ' 뒤의 평음은 된소리로 발음 / 관형사형 어미 '-(으)ㄹ' 뒤의 평음은 된소리로 발음
* **적용 예시**:
  * `갈대를` ➔ **[갈때를]**
  * `손가락질` ➔ **[손까락찔]**
  * `있을 테니` ➔ **[있쓸 테니]**
  * `할 것을` ➔ **[할 꺼슬]**

---

## 🛠️ 2. TTS 발음 교정 자동화 변환 테이블 (G2P 사전)

TTS 엔진에 대본을 입력하기 직전, 화면 표기용 자막(SRT)은 한글 맞춤법 정서법(예: `문밖의`)을 유지하고, **TTS 오디오 생성용 텍스트만 발음 교정형(예: `문밖에`)으로 변환**하여 처리합니다.

| 원문 정서법 (자막용) | 실제 표준 발음 (TTS 입력용) | 규칙 분류 |
| :--- | :--- | :--- |
| `문밖의` | **문밖에** [문바께] | 연음 + 조사 '의' [에] |
| `마님의` | **마님에** [마니메] | 조사 '의' [에] |
| `가문의` | **가문에** [가무네] | 조사 '의' [에] |
| `세도의` | **세도에** [세도에] | 조사 '의' [에] |
| `역모의` | **역모에** [영모에] | 조사 '의' [에] |
| `희망의` | **희망에** [희망에] | 조사 '의' [에] |
| `은혜의` | **은혜에** [은혜에] | 조사 '의' [에] |
| `백 년` | **뱅 년** [뱅 년] | 비음화 |
| `십 년` | **심 년** [심 년] | 비음화 |
| `군량미` | **군냥미** [군냥미] | 비음화 |
| `밤낮을` | **밤나즐** [밤나즐] | 연음화 |
| `갈대를` | **갈때를** [갈때를] | 경음화 |
| `손가락질` | **손까락찔** [손까락찔] | 경음화 |
| `빛조차` | **비쪼차** [비쪼차] | 연음 + 경음화 |

---

## 🎯 3. 시스템 적용 규칙
1. **화면 텍스트 / SRT 자막**: 원문 정서법 표준 표기 유지 (`문밖의`)
2. **TTS 오디오 합성 스트림**: 발음 최적화 텍스트 주입 (`문밖에`)
3. **영구 보관 위치**: `master_voice_standard/korean_pronunciation_rules.md`
